## 数値微分

中心差分では，導関数を次の式で近似する．

$$
f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}
$$

```python
def central_difference(f, x, h):
    return (f(x + h) - f(x - h)) / (2 * h)

def f(x):
    return x ** 2

value = central_difference(f, 3, 0.001)
print(value)
```

`f(x)=x^2`の`x=3`における導関数の値は6である．
刻み幅`h`を変えて近似値を比較する．

## 数値積分

台形公式では，区間を`n`個に分割して台形の面積を合計する．

```python
def trapezoidal(f, a, b, n):
    h = (b - a) / n
    total = (f(a) + f(b)) / 2

    for i in range(1, n):
        x = a + i * h
        total = total + f(x)

    return h * total

def f(x):
    return x ** 2

value = trapezoidal(f, 0, 1, 100)
print(value)
```

`f(x)=x^2`を0から1まで積分した正確な値は`1 / 3`である．

````{note} 演習
`f(x)=x ** 3`について次を確認する．

1. `x=2`における導関数を中心差分で近似する．
2. 0から1までの定積分を台形公式で近似する．
3. `h`または`n`を変え，誤差の変化を表にまとめる．
````

## エラーが出たとき

- `h`が0になっていないか確認する．
- 分割数`n`が正の整数か確認する．
- `range(1, n)`の範囲を確認する．
- 刻み幅を極端に小さくしても，丸め誤差により精度が上がらない場合がある．
