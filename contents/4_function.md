## 関数の定義と呼び出し

関数は，一連の処理に名前を付けたものである．
`def`で定義し，関数名の後ろに丸括弧を付けて呼び出す．

```python
def greet():
    print("こんにちは．")

greet()
```

関数へ渡す値を引数という．

```python
def greet(name):
    print(f"{name}さん，こんにちは．")

greet("佐藤")
```

## 戻り値

`return`を使うと，関数の処理結果を呼び出し元へ返せる．

```python
def average(a, b):
    result = (a + b) / 2
    return result

value = average(70, 90)
print(value)
```

`return`が実行されると，その関数の処理は終了する．

## 関数を使う理由

- 同じ処理を何度も書かずに済む．
- 処理の目的が関数名から分かる．
- 修正する場所をまとめられる．
- 小さな単位で動作を確認できる．

## エラーが出たとき

- `def`の行末にコロン`:`があるか確認する．
- 関数本体がインデントされているか確認する．
- 定義より後で関数を呼び出しているか確認する．
- 定義した引数の個数と，呼び出すときの値の個数を確認する．
