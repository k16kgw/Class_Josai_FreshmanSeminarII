## 生成AIを利用するときの原則

**生成AI**：入力された指示に基づいて，文章やプログラムなどの新しい内容を生成する人工知能である．生成された内容が正しいとは限らないため，利用者自身が確認する必要がある．

- 氏名，学籍番号，パスワードなどの個人情報を入力しない．
- 作りたいものと条件を具体的に伝える．
- 生成されたコードをそのまま提出せず，内容を読む．
- 実際に実行して動作を確認する．
- エラーや意図と異なる動作を記録し，修正する．

## ゲームの仕様

**仕様**：作成するプログラムが満たすべき機能や動作の条件である．今回は次の数当てゲームを作る．

1. コンピュータが1から20までの整数を一つ選ぶ．
2. プレイヤーが整数を入力する．
3. 正解より大きいか小さいかを表示する．
4. 正解するまで入力を繰り返す．

ゲームの流れを日本語で整理してからコードを書く．

## 数当てゲーム

```python
import random

answer = random.randint(1, 20)

while True:
    guess = int(input("1から20までの整数を入力してください："))

    if guess < answer:
        print("もっと大きい数です．")
    elif guess > answer:
        print("もっと小さい数です．")
    else:
        print("正解です．")
        break
```

ターミナルで実行する．

```console
python 第12回_<学籍番号>_<氏名>.py
```

## エラーが出たときにチェックすること

- 入力は文字列なので，整数へ変換しているか確認する．
- `if`文と`while`文のインデントを確認する．
- `import random`があるか確認する．
- 生成AIへエラー全文と直前に行った操作を伝える前に，自分でも該当行を確認する．
