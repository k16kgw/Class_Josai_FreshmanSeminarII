## 改良する機能

**機能追加**：既存のプログラムへ新しい動作や役割を加えることである．次の中から二つ以上を選べ．

- 入力できる回数を制限する．
- 正解までの回数を表示する．
- 難易度によって乱数の範囲を変える．
- ゲームをもう一度遊べるようにする．
- 整数以外が入力された場合にメッセージを表示する．

一度にすべて変更せず，一つ追加するたびに実行せよ．

## 関数を使った構成

**関数化**：一連の処理を関数としてまとめることである．ゲーム本体を関数化すると，繰り返し実行しやすくなる．

```python
import random

def play_game(max_number, max_attempts):
    answer = random.randint(1, max_number)

    for attempt in range(1, max_attempts + 1):
        guess = int(input(f"1から{max_number}までの整数："))

        if guess < answer:
            print("もっと大きい数です．")
        elif guess > answer:
            print("もっと小さい数です．")
        else:
            print(f"{attempt}回目で正解しました．")
            return

    print(f"正解は{answer}でした．")

play_game(50, 7)
```

**早期リターン**：関数の途中で`return`を実行し，残りの処理を行わずに関数を終了することである．この例では，正解した時点で`play_game`関数を終了する．
