## 関数の定義と呼び出し

**関数**：一連の処理をひとまとまりにし，名前を付けたものである．

**関数の定義**：`def`を使って，関数の名前と実行する処理を記述することである．

**関数の呼び出し**：定義した関数の名前に丸括弧`()`を付け，関数の処理を実行することである．

関数の一般的な構成は次のとおりである．関数の処理は，`def`の次の行からインデントして記述する．

```text
def 関数名(引数):
    関数を呼び出したときに実行する処理
    return 戻り値
```

引数が不要な場合は丸括弧の中を空にする．呼び出し元へ値を返さない場合は，`return`を省略できる．

```python
def greet():
    print("こんにちは．")

greet()
```

**引数**：関数へ渡す値である．関数の定義で値を受け取る変数を**仮引数**，関数を呼び出すときに渡す具体的な値を**実引数**という．次の例では，`name`が仮引数，`"佐藤"`が実引数である．

```python
def greet(name):
    print(f"{name}さん，こんにちは．")

greet("佐藤")
```

## 戻り値

**戻り値**：関数が呼び出し元へ返す処理結果である．`return`を使って指定する．

```python
def average(a, b):
    result = (a + b) / 2
    return result

value = average(70, 90)
print(value)
```

`return`が実行されると，その関数の処理は終了する．

## 関数を使う理由

- 同じ処理を何度も書かずに済む．
- 処理の目的が関数名から分かる．
- 修正する場所をまとめられる．
- 小さな単位で動作を確認できる．

## エラーが出たときにチェックすること

- `def`の行末にコロン`:`があるか確認する．
- 関数本体がインデントされているか確認する．
- 定義より後で関数を呼び出しているか確認する．
- 定義した引数の個数と，呼び出すときの値の個数を確認する．
