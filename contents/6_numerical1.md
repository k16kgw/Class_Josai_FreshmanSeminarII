## 方程式の近似解

例として，次の方程式を考える．

$$
x^2-2=0
$$

`f(x)=x^2-2`とおく．

**近似解**：方程式の厳密な解に近い数値である．

**誤差**：近似値と基準となる値との差である．数値計算では，必要な精度に応じて許容できる誤差を定める．

```python
def f(x):
    return x ** 2 - 2
```

## 二分法

**二分法**：連続関数について，`f(a)`と`f(b)`の符号が異なる区間を半分ずつ狭め，方程式$f(x)=0$の近似解を求める方法である．

```python
def bisection(f, a, b, tolerance):
    while b - a > tolerance:
        midpoint = (a + b) / 2

        if f(a) * f(midpoint) <= 0:
            b = midpoint
        else:
            a = midpoint

    return (a + b) / 2

root = bisection(f, 1, 2, 1e-8)
print(root)
```

**許容誤差**：計算を終了してよいと判断する誤差の上限である．この例の`1e-8`は$10^{-8}$を表す．
開始時に`f(a)`と`f(b)`の符号が異なることを確認する．

## ニュートン法

**ニュートン法**：関数の接線と$x$軸の交点を利用して近似値を更新し，方程式$f(x)=0$の近似解を求める方法である．現在の近似値`x`を次の式で更新する．

$$
x_{new}=x-\frac{f(x)}{f'(x)}
$$

`f(x)=x^2-2`の導関数は`f'(x)=2x`である．

```python
def derivative(x):
    return 2 * x

def newton(f, derivative, x, tolerance):
    while abs(f(x)) > tolerance:
        x = x - f(x) / derivative(x)

    return x

root = newton(f, derivative, 1, 1e-8)
print(root)
```
