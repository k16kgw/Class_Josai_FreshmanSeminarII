## UNIX系OSとターミナル

**オペレーティングシステム（OS）**：コンピュータのハードウェアやファイル，アプリケーションの実行を管理する基本ソフトウェアである．

**UNIX系OS**：UNIXの設計や操作方法を受け継ぐOSの総称である．macOSやLinuxはUNIX系OSに含まれる．

**ターミナル**：文字による命令を入力し，ファイルやプログラムを操作するためのアプリケーションである．

**コマンド**：ターミナルでコンピュータへ処理を指示するために入力する文字列である．

**カレントディレクトリ**：ターミナルで現在作業しているフォルダである．`pwd`コマンドで確認できる．

| コマンド | 動作 |
| --- | --- |
| `pwd` | 現在のフォルダを表示する |
| `ls` | ファイルの一覧を表示する |
| `cd フォルダ` | フォルダを移動する |
| `mkdir 名前` | フォルダを作成する |
| `python ファイル.py` | Pythonファイルを実行する |

`Fresh2`フォルダへ移動する．

```console
cd ~/Documents/Fresh2
pwd
ls
```

## Pythonファイルの実行

**Pythonファイル**：Pythonのソースコードを保存した，拡張子が`.py`のテキストファイルである．

**ソースコード**：プログラミング言語の文法に従い，人間が読み書きできる形で記述したプログラムである．

VS Codeで次のコードを入力して保存する．

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [1, 4, 9, 16, 25]

plt.plot(x, y, marker="o")
plt.xlabel("x")
plt.ylabel("y")
plt.title("Square numbers")
plt.savefig("square.png")
```

ターミナルで実行する．

```console
python 第11回_<学籍番号>_<氏名>.py
```

実行後に`square.png`が作成されたことを`ls`とFinderで確認する．

```{tip} 注意：Pythonコマンド
`python`で実行できない環境では`python3`を試す．
使用するPythonはJupyter Notebookと同じ環境であることが望ましい．
```

## エラーが出たときにチェックすること

- `pwd`で現在のフォルダを確認する．
- `ls`でPythonファイルが存在するか確認する．
- ファイルを保存してから実行したか確認する．
- Pythonが見つからない場合は`python3`を試す．
- Matplotlibが見つからない場合は，実行環境がJupyter Notebookと同じか確認する．
